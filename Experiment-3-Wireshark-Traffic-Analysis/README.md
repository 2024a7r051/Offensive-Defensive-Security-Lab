# Experiment No. 3

## Basic Network Traffic Analysis with Wireshark

### Aim

To capture and analyze network packets using Wireshark to identify network traffic and detect suspicious or cleartext information in a simulated network.

### Requirements

1. Kali Linux
2. Wireshark
3. Metasploitable 2
4. VirtualBox/VMware
5. Host-Only Adapter/Internal Network

### Theory

Wireshark is a network protocol analyzer used to capture and examine network packets. It helps in understanding network communication, identifying protocols, analyzing packet contents, and detecting suspicious network activity. In this experiment, Wireshark is used in a controlled lab environment to capture and analyze network traffic between virtual machines.

## Procedure

### Step 1: Start Wireshark

Open Wireshark in Kali Linux using:

wireshark

Select the network interface connected to the lab network, such as eth0.

![📷 Screenshot 1: Wireshark Interface](images/step1-wireshark-interface.png)

Step 2: Start Packet Capture

Select the appropriate network interface and start capturing packets.

Generate some network traffic by communicating with the Metasploitable 2 virtual machine.

![📷 Screenshot 2: Packet Capture](images/step2-packet-capture.png)

Step 3: Generate Network Traffic

From Kali Linux, send packets to the Metasploitable 2 machine using:

ping <Metasploitable_IP>

Observe the packets being captured in Wireshark.

![📷 Screenshot 3: ICMP Packets](images/step3-icmp-packets.png)


Step 4: Apply a Display Filter

Use the following filter to display only ICMP packets:

icmp

This helps in analyzing the ICMP traffic generated by the ping command.

![📷 Screenshot 4: ICMP Filter](images/step4-icmp-filter.png)

Step 5: Analyze TCP Traffic

Apply the following filter:

tcp

Observe the TCP packets and examine information such as source IP, destination IP, source port, destination port, and TCP flags.


![📷 Screenshot 5: TCP Analysis](images/step5-tcp-analysis.png)


Step 6: Analyze HTTP Traffic

Apply the following filter:

http

Observe HTTP requests and responses in the captured traffic.

![📷 Screenshot 6: HTTP Traffic](images/step6-http-analysis.png)

Step 7: Follow a Network Conversation

Select an HTTP/TCP packet and use:

Right Click → Follow → TCP Stream

Observe the communication between the source and destination systems.


![📷 Screenshot 7: TCP Stream](images/step7-tcp-stream.png)

Step 8: Analyze Packet Details

Select any captured packet and examine the following details:

Ethernet information
IP addresses
Transport protocol
Source and destination ports
Packet length
TCP/UDP information

![📷 Screenshot 8: Packet Details](images/step8-packet-details.png)

Step 9: Stop and Save the Capture

Stop the packet capture after completing the analysis.

Save the captured traffic using:

File → Save As

Save the file in .pcapng format for future analysis.

![📷 Screenshot 9: Saved Capture](images/step9-saved-capture.png)

Result

The network traffic was successfully captured and analyzed using Wireshark. Different protocols such as ICMP, TCP, and HTTP were identified and examined in the controlled lab environment.

Conclusion

The experiment helped in understanding network packet capture and analysis using Wireshark. It demonstrated how network protocols, packet information, and communication between systems can be examined to identify normal and suspicious network activity.
