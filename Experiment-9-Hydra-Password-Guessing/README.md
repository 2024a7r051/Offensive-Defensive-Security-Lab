## Experiment 9: Password Guessing Using Hydra

## Aim

To understand password guessing attacks using Hydra and test password security in a controlled lab environment.

## Requirements

Kali Linux
Metasploitable 2
VirtualBox
Hydra tool
SSH or FTP service
Password wordlist

## Theory

Hydra is a password-testing tool used to perform automated login attempts against different network services. It uses username and password combinations from wordlists to check whether weak credentials can be guessed. It supports services such as SSH and FTP. This experiment helps understand the importance of strong passwords and secure authentication.

## Procedure

## Step 1:Start Kali Linux and Metasploitable 2 in VirtualBox.

## Step 2:Connect both machines to the same isolated lab network.

## Step 3:Find the IP address of the target machine.

## Step 4:Check whether SSH or FTP service is running on the target.

## Step 5:Open the Kali Linux terminal and verify that Hydra is installed.

## Step 6:Prepare a small password wordlist for testing. Kali also provides wordlists such as /usr/share/wordlists/rockyou.txt.

## Step 7:Use Hydra only against the authorized lab target to perform controlled password testing.

## Step 8:Observe the output and identify weak test credentials, if any.

## Step 9:Record the findings and recommend strong passwords and account protection measures.

## Result:

Successfully studied password guessing using Hydra in a controlled virtual lab environment.

## Conclusion:

The experiment demonstrated the risks of weak passwords and highlighted the importance of strong passwords and secure authentication.
